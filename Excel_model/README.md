# Marico Limited – Excel DCF Valuation Model

This folder contains the integrated financial forecasting and intrinsic valuation model for Marico Limited.

## Model Coverage

- Five-year consolidated financial projections (FY2027–FY2031).
- Revenue and operating expense forecasting.
- Profitability, taxation and working capital projections.
- FCFF calculation and reinvestment analysis.
- WACC estimation using CAPM and beta analysis.
- Comparable-company analysis.
- Terminal value and intrinsic equity valuation.
- Sensitivity analysis.

## Valuation Methodology

The company is valued using the Discounted Cash Flow (DCF) methodology based on Free Cash Flow to Firm (FCFF).

The model incorporates historical financial performance, forward-looking operating assumptions, cost of capital estimation and terminal value calculations.

## Workbook

**Marico Valuation.xlsx**

The workbook contains the financial statements, historical analysis, forecasting schedules, WACC calculations and valuation outputs.

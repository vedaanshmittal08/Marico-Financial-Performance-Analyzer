# Marico Limited – Excel DCF Valuation Model

This folder contains the integrated financial forecasting and valuation model for Marico Limited.

### Model Coverage
- Five-year consolidated financial projections (FY2027–FY2031).
- Forecasting of revenue, operating expenses, margins and working capital.
- FCFF calculation and reinvestment analysis.
- WACC calculation using CAPM, regression beta and comparable-company analysis.
- Terminal value and intrinsic equity valuation.
- Sensitivity analysis.

### Methodology
The company is valued using the Discounted Cash Flow (DCF) methodology based on Free Cash Flow to Firm (FCFF).

**File:** `Marico_Valuation.xlsx`

*Financial information is based on publicly available company filings and market data. The model represents independent academic and analytical work, not investment advice.*
